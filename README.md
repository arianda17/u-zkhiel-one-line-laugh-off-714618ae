# One-Line Laugh-Off

A single original joke built for the make.fun One-Line Laugh-Off competition.

## How to run

Run with Node 22:

    node main.ts

The program writes the entry line to `/output/entry.txt` and prints it to stdout.

## The entry

The self-checkout told me 'unexpected item in bagging area' and I've never felt more seen.

*A cold-read one-liner: the machine's standard error reframes as personal insight.*
